# To-Do List App

A simple, modern, and interactive to-do list web application built with HTML, CSS, and JavaScript.

## Features

✅ **Add Tasks** - Quickly add new tasks with an intuitive input field
✓ **Mark Complete** - Click the checkmark button to mark tasks as done
✕ **Delete Tasks** - Remove tasks you no longer need
💾 **Auto-Save** - Your tasks are automatically saved in your browser using localStorage
🎨 **Modern UI** - Clean, responsive design with a beautiful gradient background
📱 **Responsive** - Works seamlessly on desktop and mobile devices

## How to Use

1. **Open the app** - Open `index.html` in your web browser
2. **Add a task** - Type your task in the input field and click "Add" or press Enter
3. **Complete a task** - Click the ✓ button to mark a task as completed
4. **Delete a task** - Click the ✕ button to remove a task
5. **Automatic saving** - Your tasks are saved automatically in your browser
